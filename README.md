Canvas Elements
A collection of three small projects demonstrating HTML5 Canvas concepts through drawing, music visualization, and animation.

Checkout the project at:
https://akshveer.github.io/canvas-projects/

Projects
1. Drawing Board — An interactive drawing tool with draw, erase, text box, highlight, and download features. Contains an HTML file and its own README.
2. Music Visualizer — A canvas-based visualization of music. Contains an HTML file and its own README.
3. Solar System — A canvas-based solar system demonstration. Contains HTML, JavaScript, and CSS files, along with its own README.

Getting Started
Open a project folder and launch its HTML file in a modern web browser. Refer to the README inside each folder for project-specific instructions. Keep the Solar System's HTML, JavaScript, and CSS files together so its linked resources load correctly.

Technologies
HTML5 Canvas, JavaScript, and CSS.
